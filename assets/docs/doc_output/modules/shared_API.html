register (resource, alias)
Registers a resource for serialization. If something is being serialized, and it is registered as a resource, it is replaced by `alias`. If you are registering something, make sure to register it on clientside AND serverside!

Parameters:

  • resource The resource to register (e.g. a metatable)
  • alias The unique alias used (usually a unique string value)
serialize (...)
Serializes arbitrary lua data into a string. Every lua type can be serialized, except for functions and userdata. When serializing entities, the entity(s) have their IDs removed, and are serialized by value. Only regular components are serialized; everything else in the entity is ignored.

Parameters:

  • ... The data to serialize

See also:

    deserialize
deserialize (string_data)
Deserializes string data that was serialized with serialize(). If the string data is invalid, this function will return a pair: (nil, err_str)

Parameters:

  • string_data The string data generated with serialize()

Returns:

    ... The deserialized lua objects
