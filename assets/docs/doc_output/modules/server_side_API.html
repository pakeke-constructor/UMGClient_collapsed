server.on (msg_name, func)
Listens to messages from all clients.

Parameters:

  • msg_name The message name string
  • func The callback function

See also:

Usage:

    server.on("msg_name", function(sender_username, a, b, c)
     print("msg recvd from: ", sender_username)
     print("with data: ", a,b,c)
end)
server.broadcast (msg_name, ...)
Broadcasts a message across the network to all clients. The message sent will be received by `client.on`. Entities are referenced by id when sent across the network, which is very efficient. All other lua data can be sent across, except for functions.

Parameters:

  • msg_name The message name string
  • ... The data to sent across

See also:

Usage:

    server.broadcast("my_event", 1, 2, "blah") -- Any lua data is supported, including entities.
server.lazyBroadcast (msg_name, ...)
Same as `server.broadcast`, but lazy. Lazy packets are more efficient, but not guaranteed to arrive.

Parameters:

  • msg_name The message name string
  • ... The data to sent across alongside the message name

See also:

    server.broadcast

Usage:

    server.lazyBroadcast("my_event", 1, 2, "blah") -- Any lua data is supported, including entities.

server.unicast (username, msg_name, ...)
Sends a message across the network to a specified client. The message sent will be received by `client.on`. Entities are referenced by id when sent across the network, which is very efficient. All other lua data can be sent across, except for functions.

Parameters:

  • username The username of the client to send the message to
  • msg_name The message name string
  • ... The data to sent across alongside the message name

See also:

Usage:

    server.unicast("player_username", "my_event", 1, 2, "blah") -- Any lua data is supported, including entities.

server.forceSpawn (ent)
Force spawns an entity.

When entities are created, they are buffered, and sent over the network until the next frame. This function forces it to be sent over immediately.

Parameters:

  • ent The entity to spawn
server.forceDelete (ent)
Force deletes an entity.

When entities are deleted, they aren't deleted instantly. Instead, they are buffered, and deleted the next frame. This function forces the entity deletion to go through immediately.

Parameters:

  • ent The entity to spawn
