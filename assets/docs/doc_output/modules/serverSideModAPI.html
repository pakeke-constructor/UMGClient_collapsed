server.broadcast (msg_name, ...)
Server message broadcaster Broadcasts a message across the network to all clients. The message sent will be received by `client.on`. Entities are referenced by id when sent across the network, which is very efficient. All other lua data can be sent across, except for functions.

Parameters:

  • msg_name The message name string
  • ... The data to sent across alongside the message name

See also:

Usage:

    server.broadcast("my_event", 1, 2, "blah") -- Any lua data is supported, including entities.
server.lazyBroadcast (msg_name, ...)
Lazy server message broadcaster Same as `server.broadcast`, except in a more efficient manner. The downside is that this message is not guaranteed to arrive. (Since it is using raw UDP, basically)

Parameters:

  • msg_name The message name string
  • ... The data to sent across alongside the message name

server.getPlayers (ent)
Force spawns an entity.
When entities are created, they are buffered, and sent over the network until the next frame. This function forces it to be sent over immediately.

Parameters:

  • ent The entity to spawn
